The unpacked smoke remains intentionally singular. It intercepts a synthetic `open.spotify.com` document so Chromium performs real manifest content-script injection, styled-components injection, and extension-frame messaging without network or account access. It verifies the launcher and drawer receive their expected computed styles and rejects CSP/style errors without depending on generated class hashes. The remaining Playwright journeys use the sanitized local fixture. No automated test controls or inspects a real user session.

The five frame suites preserve the former monolithic App coverage as 60 integration executions: shell 2, discovery 13, Local AI 17, voice 19, and Settings 9. `tests/frame/appTestUtils.tsx` contains only shared provider, deferred-promise, MediaRecorder, render, and interaction fixtures; product behavior remains asserted in the domain suites.
