# Support

Music Discovery Overlay is a community-maintained developer preview distributed as an unpacked Chrome extension.

## Where to ask

- **Installation, build, or usage problem:** open a GitHub issue using the bug form.
- **Feature idea:** use the feature-request form.
- **Security vulnerability or private safety concern:** follow [SECURITY.md](SECURITY.md); do not use a public issue.
- **Chrome Prompt API or Spotify service problem unrelated to this extension:** use the respective vendor's support channel.

Before opening an issue, check the [README](README.md), [manual smoke test](docs/SMOKE_TEST.md), and existing issues. Include the extension version, Chrome version, operating system, reproducible steps, and console errors when relevant. Remove account names, avatars, search history, credentials, and other personal information from screenshots or logs.

Support is provided on a best-effort basis. There is no service-level agreement, automatic extension update channel, or guarantee that Chrome's experimental on-device AI surface will be available on every compatible-looking device.
